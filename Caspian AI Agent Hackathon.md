# **Caspian AI Agent Hackathon**

##  All that you need to know about Caspian AI Agent Hackathon

About the Opportunity:

* A 15-Day AI Agent Hackathon by Caspian  
* Your agent can think. It just can't reach anyone.  
* Every agent you've built sits in a chat window, waiting for you to come to it. It can't email a customer. It can't ping you on Telegram when something is urgent. It can think, but it has no hands.  
* Caspian changes that. Install it, and your agent gets one identity across email, Slack, Discord, Telegram, WhatsApp, and other supported communication channels. With a single handler, your agent can email customers, follow up on Slack, and send you updates on Telegram or WhatsApp. You remain in control while your agent can interact across multiple channels.  
* Now we want to see what you build with it.  
* Every supported integration is available in the Caspian documentation.

Hackathon Brief:

Build an AI agent for any domain or use case.

The only requirement is that your agent must:

* Use the caspian-sdk.  
* Run on at least two supported communication channels.

If you're looking for inspiration, build an agent that solves a real problem for you—whether that's monitoring your email, notifying you when CI fails, or handling customer communication across multiple platforms.

Format:

* Fully online.  
* Duration: 15 days.

Submission Requirements:

* Public GitHub repository.  
* Demo video.

Judging Criteria:

* Creativity and originality of the use case.  
* Functional implementation.

A working prototype with a unique idea will be valued more than a polished but common solution. Finalists may be asked to provide a live demonstration.

Prizes:

* Total Prize Pool: ₹20,000 cash \+ $1,500 in Caspian credits.  
* 1st Place: ₹20,000 cash \+ $1,000 Caspian credits.  
* 2nd Place: $300 Caspian credits.  
* 3rd Place: $200 Caspian credits.

Teams may request starter credits for paid communication channels during the event by contacting the organisers.

Eligibility:

* Open to students, working professionals, and independent developers.  
* Team size: 1–2 members.  
* Solo participation is allowed.  
* Inter-college and inter-specialisation teams are allowed.  
* No prior experience with Caspian is required.  
* One submission per team.

Rules:

* All code must be written during the 15-day hackathon period.  
* Existing open-source libraries and frameworks may be used.  
* The final submission repository must be public.  
* AI coding assistants are allowed.  
* The agent must operate on at least two supported communication channels using a single handler.  
* The decision of the judges will be final.
